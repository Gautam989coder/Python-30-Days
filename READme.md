# Python 30 Days

A 30-day Python practice journey focused on strengthening my Python fundamentals, problem-solving skills, and coding confidence.

## Goal

The goal of this challenge is to practice Python consistently for 30 days and improve my ability to:

- Understand Python fundamentals
- Write clean and readable code
- Solve programming problems
- Improve logical thinking
- Build small Python programs
- Prepare for Python developer interviews

##  Topics

During this 30-day journey, I will practice:

- Variables & Data Types
- Strings
- Lists
- Tuples
- Sets
- Dictionaries
- Conditions
- Loops
- Functions
- File Handling
- Exception Handling
- OOP
- Modules & Packages
- Problem Solving
- Mini Projects
